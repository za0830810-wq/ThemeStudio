# استوديو الثيمات (Theme Studio)

خلفية حية للأندرويد (الرئيسية والقفل) فيها:
- ساعة قابلة للتحكم: الشكل، الحجم، الموضع، اللون، الشفافية، 12/24 ساعة، أرقام عربية، التاريخ.
- ثيمات ثابتة ومتحركة + «صورتي» من المعرض.
- ذكاء اصطناعي داخل الهاتف (نموذج U²-Net الصغير، مرخّص Apache-2.0) يفصل الشكل الرئيسي في الصورة
  فتظهر الساعة **خلفه**. يعمل بدون إنترنت، والتطبيق لا يطلب صلاحية الإنترنت أصلاً.
- إضافة خطوط في أي وقت: TTF / OTF / TTC / OTC / WOFF (WOFF2 غير مدعومة في أندرويد).

## طريقة التجميع (APK)
1. ثبّت Android Studio ثم افتح هذا المجلد (File ▸ Open).
2. انتظر انتهاء Gradle Sync (يحتاج إنترنت مرة واحدة لتنزيل الأدوات).
3. Build ▸ Build APK(s). الملف يظهر في app/build/outputs/apk/debug/app-debug.apk
4. انقله للهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة» لمدير الملفات).

أو ارفع المجلد إلى مستودع GitHub وشغّل Actions ▸ Build APK، ثم نزّل الملف من Artifacts.
